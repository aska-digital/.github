# .github

Aska Digital's organisation-wide files: the source repository for [the organisation's Discussions](https://github.com/orgs/aska-digital/discussions)
(the public main board), and the default discussion forms for every aska-digital repository.

- [FORUM.md](FORUM.md): the main board's rules, categories and which repositories have boards.
- [FORUM-STANDARD.md](FORUM-STANDARD.md): the forum standard shared with Foundation-0 and Proven-Commons.
- `.github/forum/`: the board's manifest and gate; `.github/DISCUSSION_TEMPLATE/`: its forms.
